# 词法分析

> 掌握：词法分析程序的构造，正规式和正规文法到有穷自动机的转换，NFA到DFA的转换、DFA的化简
> 理解：正规文法、正规式、DFA的概念、NFA的概念
> 了解：词法分析程序的自动构造工具

- 为什么区分词法分析与语法（句法）分析？（层次、效率、移植性，词有限封闭、句无限开放，自动机、上下文无关文法）
- 正规文法、正规式/正则表达式、自动机及其描述的语言
- 正规式 -> 正规文法
  - $A\to\alpha|\beta$ -> $A\to\alpha$、$A\to\beta$
  - $A\to\alpha\beta$ -> $A\to\alpha B$、$B\to\beta$
  - $A\to\alpha^*\beta$ -> $A\to\alpha A$、$A\to\beta$
  - $A\to(\alpha|\beta)B$ -> $A\to\alpha B$、$A\to\beta B$
- 正规文法 -> 正规式
  - 或合并
  - 右提出
  - 循环闭包
  - 往后代
  - 往前代
- 有穷自动机/有限自动机
  - 确定的有穷自动机 DFA 和不确定的有穷自动机 NFA
  - 状态图、状态表
  - 接受/识别
  - NFA -> DFA：子集法
    - 状态集合的 $\varepsilon$-闭包（$\mathrm{\varepsilon-closure}(I)$）、$a$ 弧转换（$\mathrm{move}(I,a)$）
  - DFA 的化简：分割法
    - 等价状态、多余状态
    - 一致性条件、蔓延性条件
  - NFA -> 正规式
    - 超级初态、超级终态
    - 不断去重边、消点
  - 正规式 -> NFA
    - 逐边替换
  - NFA -> 正规文法
    - 同名非终结符、走非空步
  - 正规文法 -> NFA
    - 同名状态、新增终态

# 目标程序运行时的存储组织

> 掌握：	参数传递的几种方式

- 存储区：目标代码区、数据空间

- 分配策略
  - 静态存储分配：不允许递归、数据类型不可变体积；易于实现

- 参数传递

  - 传（地）址
