# 做题的通常步骤

1. 读题建模
   - 重新叙述问题，厘清条件，清晰所求
   - 关注数据范围
2. 探索性质
   - 手模激发直觉
   - 加强条件分类讨论
   - 特殊情况特判结果
   - 关注背景的对象性质
   - 关注结构，迁移类似对象的结论
   - 关注解的必要性质
   - 探索问题依赖
3. 给出思路
   - 打开思维想
   - 先往简单了想
   - 猜一个思路
   - 否定思路要比肯定思路谨慎
   - 不妨换一个方向
   - 审视之前思路不正确的地方，迭代调整
   - 一些套路
     - 从答案域入手讨论
     - 灵活转变思考对象——换个角度
     - 转化问题：等效转换，数形结合等
     - 若干形式的小问题：统筹或组合
     - 分类讨论逐个分析
     - ...
4. 论证思路
   - 重新叙述层次问题，不要遗漏条件
   - 掂量条件与结论的强弱，寻找条件或减弱目标
   - 在高层次尽可能给好的条件，传递更多的信息
   - 边界、极端情况讨论
   - 检查复杂度：粗检、细检
5. 捋清做法
6. 代码实现
   - 结构化实现，恰当封装
   - 层次化实现
     - 输入
     - 预处理
     - 处理
     - 输出
     - 资源回收
