# 形式化、抽象化、建模、理想化、封装、泛化、模板化的辨析

补充：具体化、形象化、迁移

| 词     | 对象 | 意思               |
| ------ | ---- | ------------------ |
| 形式化 | 问题 | 规范化，常符号化   |
| 抽象化 |      | 忽略细节，抽出结构 |
| 具体化 |      | 补充细节           |
| 形象化 |      | 引入几何直观       |
| 建模   |      | 非线性形式化       |
| 迁移   |      | 寻找相同的结构     |
| 理想化 |      | 近似简化的一种     |
| 封装   | 做法 | 引入黑盒           |
| 泛化   |      | 推广               |
| 模板化 |      | 固定               |
