# 做题的一般思路

- 建模
- 性质
- 思考
  - 先打开思维想
  - 先想简单的
  - 不要耗死于一种思路
  - 层次化地思考，抽象层次目标，常重新描述问题，但注意不要遗漏条件
  - 掂量目标与条件的强弱，不匹配时考虑找寻遗漏的条件或减弱目标
  - 问题存在容易模拟的结构时，先“手玩”寻找规律
  - 一些套路
    - 从答案域入手
    - 若干形式相同小问题：统筹和组合
    - 灵活转变思考对象——换个角度
    - 灵活迁移不同对象间的结论
    - 分类讨论加强条件推导性质
  - 讨论极端情况是否结论存在例外
  - 检查结论正确性：可严格正确、形象正确，不可直觉正确（可根据直觉正确思考，但一定要论证）
  - 检查复杂度：粗检（往坏了算，还能过就过，不能过不着急 ban，再细检）、细检（展开）
- 做法
  - 再次考虑能否简化结论及做法
- 实现
  - 再次厘清做法
  - 层次化地实现
    - 输入
    - 预处理
    - 处理（函数式、结构式）
    - 输出
    - 回收资源
  - 封装地实现，关键问题：在哪封装？
  - 带模板
