# [P14460 【MX-S10-T1】『FeOI-4』寻雾启示 - 洛谷](https://www.luogu.com.cn/problem/P14460?contestId=287507)

## 题意

一个人在数轴整点上移动，$0$ 时刻时活动范围只为原点处，需要通过搭“羊毛”扩大活动范围. $k$、$2k$、$3k\dots$ 时刻，原点处都会生成一个“羊毛掉落物”. 羊毛掉落物可以叠加、不会消失，人在原点处时可以被瞬间拾起.

在位置 $i$ 的人可以进行下面两种操作：

- 搭路：如果人手上存在羊毛，并且位置 $i+1$ 还是不能活动的范围，则消耗 $t_1$ 时间和一个羊毛，将位置 $i+1$ 扩大为活动范围，并移动到 $i+1$ 上
- 移动：消耗 $t_2$ 时间前往 $i+1$ 处或 $i-1$ 处，要求前往处是活动范围

给定 $m$、$k$、$t_1$、$t_2$，分别求人到达 $1$、$2$、$\dots$、$m$ 位置的最早时刻.

给定的数都是正整数，且 $m\leq10^5$、$k,t_1,t_2\leq10^9$. 多测，$T\leq10$.

## 分析

考虑 dp. 用 $d_s$ 表示人到达 $s$ 处的最早时刻.

人到达 $s$ 处的前几步操作必然是从 $s$ 前的某个位置 $s-j$ 上回到原点，取够足够的羊毛后搭路到达 $s$ 处，即 $d_s\larr\Delta(p_{s-j}+(s-j)t_2)+(s-j)t_2+jt_1$，其中 $p_{s-j}$ 为到达 $s-j$ 处的一个可能的时刻，$\Delta$ 为从 $p_{s-j}$ 时刻开始从 $s-j$ 往原点走，到达并取够足够的羊毛的最早时刻.

显然，有 $\Delta=\max\{ks,p_{s-j}+(s-j)t_2\}$；$d_s$ 考虑的是最早时刻，$p_{s-j}$ 也考虑最早时刻即可. 于是有状态转移方程：
$$
d_s=\begin{cases}
0&,s=0\\
\min_{j=1}^s\varphi_s(j)&,\text{else}
\end{cases}
$$
其中 $\varphi_s(j):=\max\{ks,d_{s-j}+(s-j)t_2\}+(s-j)t_2+jt_1$.

再考虑优化，考察 $\varphi_s$ 的性质. 不难发现，这是个严格单谷的离散函数，可三分. 复杂度 $O(Tm\log m)$.

## 实现

比较少写离散函数的三分，注意细节（答案可能范围小于等于 $3$ 时，**都**要特判）.

# [P14461 【MX-S10-T2】『FeOI-4』青年晚报 - 洛谷](https://www.luogu.com.cn/problem/P14461?contestId=287507)

## 题意

有两列 $m$ 次多项式：$f_0(x),f_1(x),\dots,f_n(x)$ 和 $g_0(x),g_1(x),\dots,g_n(x)$，存在递推式：
$$
f_i(x)=g_{i-1}(x)+g_{i-1}'(x)\\
g_i(x)=f_{i-1}(x)-f_{i-1}'(x)\\\forall i>1
$$
给定 $m$、$n$，以及 $f_0(x)$ 和 $g_0(x)$ 的各项系数，求  $f_n(x)$ 和 $g_n(x)$ 的各项系数，对 $10^9+7$ 取模.

给定的数都是整数，$m\in[0,5\times10^3]$，$n\in[2,10^9]$， $f_0(x)$ 和 $g_0(x)$ 的各项系数在区间 $[0,10^9]$ 范围内，且保证最高次项系数不为 $0$.

## 分析

分别将 $f_i(x)$、$g_i(x)$ 的各项系数（从低次到高次）写成向量 $\boldsymbol{f_i}$、$\boldsymbol{g_i}$，则递推式可写成矩阵形式：
$$
\boldsymbol{f_i}=A\boldsymbol{g_{i-1}}=AB\boldsymbol{f_{i-2}}\\
\boldsymbol{g_i}=B\boldsymbol{f_{i-1}}=BA\boldsymbol{g_{i-2}}
$$
其中 $A$、$B$ 分别为：
$$
A=\left[\begin{matrix}
1 & 1 &   &        &        &     \\
  & 1 & 2 &        &        &     \\
  &   & 1 & 3      &        &     \\
  &   &   & \ddots & \ddots &     \\
  &   &   &        & 1      & n-1 \\
  &   &   &        &        & 1   \\
\end{matrix}\right]\\
B=\left[\begin{matrix}
1 & -1 &    &        &        &        \\
  & 1  & -2 &        &        &        \\
  &    & 1  & -3     &        &        \\
  &    &    & \ddots & \ddots &        \\
  &    &    &        & 1      & -(n-1) \\
  &    &    &        &        & 1      \\
\end{matrix}\right]
$$
再简单讨论后就可以用快速幂实现，复杂度 $O(m^3\log n)$.

等下，$m^3$ 似乎过不了本题！再考虑矩阵对角化……这两个矩阵也是不可对角化矩阵！

发现两个矩阵其实很稀疏，信息密度很低，使用矩阵乘法求解，信息处理量与计算量的比很低，考虑用更精炼的表达. 向量的矩阵变换其实可以写成多项式的算子：
$$
f_i(x)=\left(1+\frac{\mathrm{d}}{\mathrm{d}x}\right)g_{i-1}(x)=\left(1-\frac{\mathrm{d}^2}{\mathrm{d}x^2}\right)f_{i-2}(x)\\
g_i(x)=\left(1-\frac{\mathrm{d}}{\mathrm{d}x}\right)f_{i-1}(x)=\left(1-\frac{\mathrm{d}^2}{\mathrm{d}x^2}\right)g_{i-2}(x)\\
$$
其中 $1$ 表示恒等算子.

$n$ 为偶数时，对于 $f_n(x)$，有（其他情况、$g_n(x)$ 类似，不再讨论）：
$$
f_n(x)=\left(1-\frac{\mathrm{d}^2}{\mathrm{d}x^2}\right)^{\frac{n}{2}}f_{0}(x)\\
$$
根据一点点算子数学的知识，可以使用二项式定理展开==（形式上很自然，但想想为什么）==：
$$
\left(1-\frac{\mathrm{d}^2}{\mathrm{d}x^2}\right)^{\frac{n}{2}}=\sum_{i=0}^{\frac{n}{2}}\binom{\frac{n}{2}}{i}(-1)^i\frac{\mathrm{d}^{2i}}{\mathrm{d}x^{2i}}
$$
由于 $f_0(x)$ 是 $m$ 次多项式，求导的次数超过 $m$ 时恒为零，所以上式最多只用保留前面的 $\lfloor\frac{m}2\rfloor+1$ 项.

递推处理每一项的系数，求出每一项“作用”到 $f_0(x)$ 后的结果再累加到答案即可，其中还涉及到一点点逆元的求解，复杂度 $O(m^2)$.

## 实现

比较少写多项式求导的代码，注意理顺：

```cpp
#include <bits/stdc++.h>

#define MA(a, b) ((1ll * (a) + (b)) % M)
#define MT(a, b) ((1ll * (a) * (b)) % M)
#define MR(x) MA(-x, M)
#define MM(a, b) MA(a, MR(b))

using namespace std;

const int N = 5e3+5;
const int M = 1e9+7;
int n, m;
int f0[N], g0[N];
int f1[N], g1[N];
int fn[N], gn[N];
int rev[N];
int cls[N];

int mpow(int p, int q)
{
    int res = 1;
    while (q) {
        if (q & 1) {
            res = MT(res, p);
        }
        q >>= 1;
        p = MT(p, p);
    }
    return res;
}

void add2(int f[], int i, int v[], int c)
{
    int fr = 1;
    int dv = 1;
    for (int j = 2; j <= i; ++j) fr = MT(fr, j);
    for (int j = i; j <= m; ++j) {
        f[j - i] = MA(f[j - i], MT(MT(fr, dv), MT(c, v[j])));
        fr = MT(fr, j + 1);
        dv = MT(dv, rev[j - i + 1]);
    }
}

int main()
{
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);

    cin >> n >> m;
    for (int i = 0; i <= m; ++i) {
        cin >> f0[i]; // 从低次到高次输入 f0(x) 的系数，下同
    }
    for (int i = 0; i <= m; ++i) {
        cin >> g0[i];
    }
    for (int i = 0; i <= m; ++i) {
        f1[i] = MA(g0[i], (i < m ? MT(i + 1, g0[i + 1]) : 0));
    }
    for (int i = 0; i <= m; ++i) {
        g1[i] = MM(f0[i], (i < m ? MT(i + 1, f0[i + 1]) : 0));
    }

    for (int i = 1; i <= m + 5; ++i) {
        rev[i] = mpow(i, M - 2); // 有线性逆元做法，不过这里这样子做也不影响复杂度
    }

    int c = 1;
    for (int i = 0; 2 * i <= m && i <= n / 2; ++i) {
        cls[2 * i] = c; // 处理每一项算子前的系数，cls[2 * i] 就是求 2 * i 阶导那一项的系数
        c = MR(MT(MT(c, (n / 2 - i)), rev[i + 1]));
    }

    for (int i = 0; i <= m; i += 2) {
        add2(fn, i, (n & 1) ? f1 : f0, cls[i]); // 求 f0/f1(x) 的 i 阶导，乘上相应系数再累加到 fn(x)
        add2(gn, i, (n & 1) ? g1 : g0, cls[i]);
    }

    for (int i = 0; i <= m; ++i) {
        cout << fn[i] << ' ';
    }
    cout << endl;
    for (int i = 0; i <= m; ++i) {
        cout << gn[i] << ' ';
    }
    cout << endl;

    return 0;
}
```

## 复盘

矩阵加速很快？也不一定哦，毕竟个立方摆在那里.

优化的一个思路——提升信息-计算比.

这道题也可以通过观察规律解决，不过也就是通过归纳得出了前文最后的结论，没什么新的东西.

矩阵表述的转换过程与微分算子表述的转换过程等价，为何推导结论有区别？原因在于全体微分算子的空间只同构于全体矩阵集合的某个子空间. 将微分变换写成矩阵变换，实际上弱化了变换表达式，失去了微分算子天然带有的复合可交换等性质. 当然，也意味着可以具体讨论矩阵的相应子空间，并建构出相同的性质和导出相同的结论.
