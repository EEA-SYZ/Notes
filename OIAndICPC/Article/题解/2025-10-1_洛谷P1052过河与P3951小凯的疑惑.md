# [P1052 [NOIP 2005 提高组] 过河 - 洛谷](https://www.luogu.com.cn/problem/P1052)

## 题意

数轴上有一片区域 $(0,L)$，区域上有 $M$ 个石头，都在整点上. 一只青蛙从 $0$ 处出发，每次可前进的距离为 $[S,T]$ 间的正整数.

给定正整数 $L$、$M$、$S$、$T$ 以及石头的坐标，求青蛙跳出区域最少要踩到的石头数.

$L$、$M$、$S$、$T$ 都是正整数，且 $L\in[1,10^9]$，$1\leq S\leq T\leq10$，$M\in[1,100]$.

## 分析

考虑 dp.

记 $\mathrm{dp}_p$ 表示青蛙跳从 $p$ 处出发跳出区域最少要踩到的石头数，则：
$$
\mathrm{dp}_p=
\begin{cases}
0&,p\geq L\\
\min_{j=S}^{T}\{\mathrm{dp}_{p+j}+\sigma_{p+j}\}&,\text{else}
\end{cases}
$$
其中 $\sigma_p$ 为 $p$ 处的石头数. 所求为 $\mathrm{dp}_0$.

复杂度 $O(LT)$，需优化.

注意到 $L$ 很大 $M$ 却很小，这启示我们，在很多位置上有 $\mathrm{dp}_p=\min_{j=S}^{T}\{\mathrm{dp}_{p+j}\}$ 成立，只有在石头附近的位置才需要特别考虑.

非特别情况下，$\mathrm{dp}_p$ 可以往后一直转移为 $p$ 一段长度不超过 $T$ 的区间内的状态的最小值，即有 $\mathrm{dp}_p=\min_{j=\max\{kS,(k-1)T\}}^{kT}\{\mathrm{dp}_{p+j}\}$，其中 $k$ 为正整数；直到区间接近下一个石头所在的位置，即存在一个 $k$，使得 $\mathrm{dp}_p=\min_{j=\max\{kS,(k-1)T\}}^{kT}\{\mathrm{dp}_{p+j}+\sigma_{p+j}\}$. 中间的很多状态可以直接跳过，是不需要考虑的.

我们希望 $\mathrm{dp}_p$ 在转移到下一个石头附近时就都能得到求解，而不需要继续转移到下下个石头的位置，这就要求每一个石头前后 $T$ 个单位距离内的位置的状态要存在.

所以，我们只记录每一个石头前后 $T$ 个单位距离内的位置的状态，就可以完成任意状态的转移：
$$
\mathrm{dp}_p=
\begin{cases}
0&,p后没有石头\\
\min_{j=\max\{k(p)S,(k-1)T\}}^{k(p)T}\{\mathrm{dp}_{p+j}+\sigma_{p+j}\}&,else
\end{cases}
$$
其中 $k$ 能使得区间转移到下一个石头附近.

复杂度 $O(MT^2K)$，其中 $K$ 为求解 $k$ 的复杂度.

### 解法一

我们可以进行[模拟](https://www.luogu.com.cn/record/237713645)避免对 $k$ 的进一步分析. 这可行，但徒增更多对细节的分析，很易错.

### 解法二

继续对 $k$ 进行分析，不难发现：
$$
k(p)=\min\{k\in\Z^+|p+kT\geq\mathrm{nt}(p)\}=\Big\lceil\frac{\mathrm{nt}(p)-p}T\Big\rceil
$$
其中 $\mathrm{nt}$ 为 $p$ 位置下一个石头的位置，这在对要记录状态的位置离散化后可以在 $O(T)$ 内求解.

总复杂度 $O(MT^3)$.

## 实现

```cpp
#include <bits/stdc++.h>

using namespace std;

const int M = 105;
int pls[M];

int kcnt = 1;
int kls[M * 10];
int iss[M * 10];

int dp[M * 10];

void pushk(int x)
{
    if (x <= kls[kcnt]) return;
    ++kcnt;
    kls[kcnt] = x;
}

int ceil(int a, int b)
{
    if (a % b) {
        return a / b + 1;
    }
    return a / b;
}

int nt(int i)
{
    while (i < kcnt) {
        ++i;
        if (iss[i]) return i;
    }
    return -1;
}

int main()
{
    int L;
    int s, t, m;
    cin >> L >> s >> t >> m;
    for (int i = 1; i <= m; ++i) {
        cin >> pls[i]; // 石头的位置
    }
    sort(pls + 1, pls + 1 + m);
    for (int i = 1; i <= m; ++i) {
        for (int k = -t; k <= t; ++k) {
            pushk(pls[i] + k); // 记录状态的位置，顺便离散化
        }
    }
    for (int i = 1, p = 1; i <= kcnt; ++i) {
        if (kls[i] == pls[p]) {
            ++iss[i]; // 离散化位置的石头的数量
            ++p;
            if (p > m) break;
        }
    }

    // 在离散化位置上 dp
    for (int i = kcnt; i > 0; --i) {
        auto ntt = nt(i); // 下一个石头的离散化位置
        if (ntt == -1) continue;
        dp[i] = M;
        auto k = ceil(kls[ntt] - kls[i], t);
        int rl = kls[i] + max(k * s, (k - 1) * t), rr = kls[i] + k * t; // 转移到的区间
        int p = i + 1;
        while (kls[p] < rl) ++p; // 寻找转移到的离散化区间
        while (kls[p] <= rr) {
            dp[i] = min(dp[i], dp[p] + iss[p]);
            ++p;
        }
    }

    cout << dp[1] << endl;
    
    return 0;
}
```

# [P3951 [NOIP 2017 提高组] 小凯的疑惑 - 洛谷](https://www.luogu.com.cn/problem/P3951)

## 题意

给定互素的正整数 $a$、$b$，求 $\max\Z\setminus\{pa+qb|p,q\in\N\}$.

正整数 $a,b\in[1,10^9]$，且 $a$、$b$ 互素，并保证有解.

## 分析

为了保证有解，从所有 $a$ 能表示的点出发，分别不断地跳 $b$ 单位的距离，在覆盖所有整点前，不会重复已经跳到过的点，这就是说，有解时，$pa,pa+b,\dots,pa+(a-1)b$ 构成模 $a$ 意义下的完全剩余系.

所求 $x$ 必定落在某个剩余类 $[pa+kb]=[kb]$ 中，即 $x=pa+kb$，其中 $k\in\Z$ 且 $k\in[0,a-1]$，并且为了保证 $x$ 的性质，对 $p$ 提出了进一步的要求 $p\in\Z^-$.

由于 $x$ 是最大值，所以 $p=-1$、$k=a-1$，即 $x=-a+(a-1)b=ab-a-b$.

复杂度 $O(1)$.

## 实现

略.

## 复盘

求解最值的一个方法：

求解最值时，不妨设为求解最大值 $x=\max A$，其中 $A=\{x\in U|P(x)\}$，可尝试划分全集 $U$ 为 $\{A_i\}_n$，并且 $A_i\cap A\not=\varnothing$，则 $x=\max_i\{\max A_i\cap A\}$.

在这题中，$x=\max\Z\setminus\{pa+qb|p,q\in\N\}=\max_{k=0}^{a-1}\{\max[kb]\setminus\{pa+qb|p,q\in\N\}\}=\max_{k=0}^{a-1}\{\max\{pa+kb|p\in\Z^-\}\}$. 实际上，有 $\Z\setminus\{pa+qb|p,q\in\N\}=\bigcup_{k=0}^{a-1}[kb]\setminus\{pa+qb|p,q\in\N\}=\bigcup_{k=0}^{a-1}\{pa+kb|p\in\Z^-\}=\{pa+kb|k\in\Z,k\in[0,a-1],p\in\Z^-\}$，所以 $x=\max_{\text{condition}}\{pa+kb\}$.
